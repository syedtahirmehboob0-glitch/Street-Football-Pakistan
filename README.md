# Street Football: Pakistan

Playable Godot 4.x integrated check build for a 3v3 Pakistan street-football game.

## Included
- Pakistan 3v3 vs opponent 3v3
- Player movement and sprint
- Ball possession
- Passing and shooting
- Player switching
- Tactical AI positioning and ball chasing
- Goals and kickoff reset
- 3-minute match timer
- Full-time result screen
- Basic touch/drag movement support
- Procedural field and player visuals; no external art assets required

## Desktop controls
- WASD / Arrow keys — Move
- Shift — Sprint
- Space — Shoot
- E — Pass
- Tab — Switch player
- R — Restart after full time

## Run
Open `project.godot` in Godot 4.x and press Play.

This is the integrated playable foundation/check build, not a signed Google Play production release yet. Android export/signing, final art/animation/audio, menus, progression, shop/cosmetics, ads, and production QA are still separate release work.
